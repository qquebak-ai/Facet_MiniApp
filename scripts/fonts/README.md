Montserrat, переменное начертание, подмножества латиницы и кириллицы
(скачано с Google Fonts). Лицензия SIL Open Font License 1.1:

Файлы лежат в репозитории, а не тянутся при сборке: баннер должен
собираться одинаково на любой машине и без сети. Скрипт вшивает их в SVG
как base64 — иначе Chromium рисует Liberation Sans, и заголовок выглядит
казённо.
