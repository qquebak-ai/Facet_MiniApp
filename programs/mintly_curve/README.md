# Кривая Mintly для Solana

Программа, которая даёт запускать токены в Solana так же, как кривая на
Tact даёт запускать их в TON: цена считается по формуле, а не по чужим
заявкам, поэтому купить можно с первой секунды после запуска.

Формула та же, что и на TON, — постоянное произведение на виртуальных
резервах:

```text
k = (virtual_sol + real_sol) * (virtual_tokens - tokens_sold)
```

Токены не лежат на складе: право выпуска принадлежит самой кривой (PDA),
она печатает их в момент покупки и сжигает при продаже. Вынуть запас мимо
кривой нельзя — его не существует, пока за него не заплатили.

Когда набирается порог (85 SOL), торговля закрывается: кривая выпускает
получателю непроданный остаток вместе с отложенным запасом под
ликвидность, снимает право выпуска навсегда и одним переводом отдаёт
собранные монеты. Монеты и токены и есть будущая пара на бирже, причём
цена в ней совпадает с последней ценой кривой — без запаса в пару
попадали бы одни остатки, и первый же покупатель платил бы втридорога.

Закрыть может кто угодно: важно не кто нажал, а что порог достигнут.
Приложение делает это расписанием (`/api/wallet-solana?action=graduate`),
комиссию платит внутренний кошелёк владельца токена.

## Параметры по умолчанию

| Что | Значение |
| --- | --- |
| Разрядность | 6 |
| Эмиссия | 1 000 000 000 |
| Продаёт кривая | 800 000 000 |
| Запас под ликвидность | 200 000 000 |
| Виртуальные SOL | 30 |
| Виртуальные токены | 1 073 000 000 |
| Порог закрытия | 85 SOL |
| Комиссия площадки | 1% (потолок в коде — 5%) |

Задаются в `api/solana-launch.js` (объект `КРИВАЯ`) и проверяются самой
программой при создании кривой.

## Сборка

```sh
cargo test                      # проверка математики кривой
cargo build-sbf                 # сборка под сеть, результат в target/deploy
```

Готовые бинарники лежат в `build/` — их можно разворачивать без установки
Rust:

* `mintly_curve-v3.so` — для сетей, где старые версии SBPF уже отключены
  (текущий мейннет и локальный валидатор). **Разворачивать нужно этот.**
* `mintly_curve-v0.so` — запасной, на случай если узел откажется принимать
  третью версию.

## Проверка на локальной сети

```sh
solana-test-validator --reset \
  --clone-upgradeable-program metaqbxxUerdq28cj1RbAWkYQm3ybzjb6a8bt518x1s \
  --url https://api.mainnet-beta.solana.com     # нужен Metaplex для метаданных

solana program deploy build/mintly_curve-v3.so
KEY=~/.config/solana/id.json PROGRAM=<Program Id> FEE=<адрес кошелька> \
  node programs/mintly_curve/test/local.mjs
```

Скрипт проходит весь путь: создаёт токен с метаданными, заводит кривую,
покупает дважды (вторая покупка должна дать меньше токенов — цена растёт),
продаёт часть обратно и печатает состояние кривой.

Отдельно проверяется закрытие — там всё самое дорогое:

```sh
KEY=~/.config/solana/id.json PROGRAM=<Program Id> FEE=<адрес> \
  node programs/mintly_curve/test/graduate.mjs        # закрытие как есть
KEY=… PROGRAM=… FEE=… LIQ=<адрес получателя> \
  node programs/mintly_curve/test/graduate-server.mjs # тем же кодом, что на сервере
```

Второй скрипт покупает сразу на 86 SOL, закрывает кривую и сверяет цену
в будущей паре с последней ценой кривой: расхождение должно быть меньше
процента.

## Развёртывание в мейннете

```sh
# 1. Установить инструменты Solana (один раз)
sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"

# 2. Кошелёк, с которого идёт развёртывание
solana-keygen new -o ~/mintly-deployer.json
solana config set --keypair ~/mintly-deployer.json --url https://api.mainnet-beta.solana.com
solana address                  # пополнить: аренда программы 0.64 SOL плюс комиссии

# 3. Развернуть
solana program deploy programs/mintly_curve/build/mintly_curve-v3.so
```

Команда напечатает `Program Id` — это и есть адрес программы.

## Бесплатная проверка в devnet

Если денег на мейннет пока нет, всё то же самое работает в тестовой сети —
монеты там выдаются даром:

```sh
solana config set --url https://api.devnet.solana.com
solana airdrop 2
solana program deploy programs/mintly_curve/build/mintly_curve-v3.so
```

В настройках приложения тогда `SOLANA_RPC=https://api.devnet.solana.com`,
а кошелёк в Phantom нужно переключить на devnet. Токены там ненастоящие,
зато весь путь — запуск, покупка, продажа — проходится целиком.

## Настройки приложения

В Vercel → Settings → Environment Variables:

| Переменная | Значение |
| --- | --- |
| `SOLANA_CURVE_PROGRAM` | Program Id из предыдущего шага |
| `SOLANA_FEE_ACCOUNT` | кошелёк площадки: туда идёт комиссия сделок |
| `SOLANA_LIQUIDITY` | куда уходит ликвидность после закрытия кривой |
| `SOLANA_RPC` | узел сети (публичный не выдержит нагрузки) |

Пока `SOLANA_CURVE_PROGRAM` не задан, запуск в Solana выключен целиком:
приложение не показывает ни выбора сети в форме, ни кнопки запуска в
разделе Solana.

## Что ещё не сделано

После закрытия кривой ликвидность уходит на `SOLANA_LIQUIDITY` одним
переводом — своего AMM-пула в Solana пока нет, в отличие от TON, где его
роль играет `contracts/src/liquidity_pool.tact`. До тех пор торговля
закрывшимся токеном идёт через биржи сети (Jupiter), куда пул заводится
руками.
